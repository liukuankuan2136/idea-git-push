4. 安装、配置与升级

  1. IDEA 打开 Settings → Plugins，点击齿轮，选择 Install Plugin from Disk…。
  2. 选择 D:\code\my-workspace\git-push-idea\build\distributions\git-push-idea-0.1.0.zip，按 IDEA 提示重启。
  3. 进入 Settings → Tools → Issue Link Push，填写 DevOps 用户名和浏览器登录请求中的 password 密文，并设置 commit 模板、超时、缓存、追加/覆盖模式与任务模板模式。
  4. 日常使用从 Tools → Issue Link Push 进入；Git 类命令执行前先在 IDEA 中暂存改动。
  5. 升级时构建更高版本 ZIP，再次使用 Install Plugin from Disk… 覆盖。设置和 PasswordSafe 凭据会保留；降级前建议备份 IDEA 设置目录。

5. 建议的最终人工验收顺序

  1. 先配置账号，执行一次“关联 DevOps 任务仅提交”，核对 commit 文本和新增工时。
  2. 在测试分支验证“提交并推送”和“amend 并推送”，同时模拟一次 push 失败确认恢复提示。
  3. 分别以简易、普通、标杆模式创建测试任务，重点核对 C04 工时类型与 C05 隐藏章节。
  4. 提交一条可撤销的测试日报，并核对工时不足与逾期提示。
  5. 选取已知区域异常样本运行区域检查，与网页端人工结果比对。
  6. 确认无误后将 git-push-idea 初始化为 Git 仓库；不要提交 HAR、凭据、build 或沙箱目录。
