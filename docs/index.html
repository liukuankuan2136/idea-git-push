结论先行

可迁移

核心业务逻辑没有依赖 VS Code 特有能力；DevOps 访问、提交信息生成、区域规则和工时计算均可直接按领域逻辑重写为 Kotlin。

不建议逐屏照搬

VS Code 的 QuickPick/InputBox 造成一个功能连续弹出 7–20 次。IDEA 版本应按业务动作使用一个 DialogWrapper，在窗内完成级联、校验、预览和执行。

先做本机定向版

构建基线锁定本机 261.26222.65，兼容上界为 261.*。不承诺 2025.x、2026.2 或其他 JetBrains IDE。

升级走私有 ZIP

首期通过 Install Plugin from Disk 安装覆盖；稳定后可增加公司 HTTPS 自定义插件仓库，实现 IDEA 内自动发现更新。
